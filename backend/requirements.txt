# Step 6: PDF signature integrity and duplicate detection
# Resolved on Python 3.10 / Windows here.
#
# pyHanko locates signature fields, reads /ByteRange and derives how much of
# the file a signature covers. We do NOT use its validation API: the scope is
# integrity only, with no certificate-chain or trust-store checking, which is
# also what keeps this module off the network. The digest comparison itself is
# ours (hashlib + asn1crypto) because pyHanko's `external_digests` is a cache of
# *recomputed* digests, not the signed value — comparing the two would always
# agree. See app/signatures/README.md.
#
# It is a heavy install: 20-odd transitive packages including aiohttp, lxml,
# oscrypto and cryptography. Accepted because re-deriving PDF revision
# boundaries by hand is where subtle bugs live, and because a reference
# implementation signing the fixtures is what stops our checker from testing
# only its own assumptions.
pyhanko==0.38.0
# Pulled in by pyhanko, and imported directly for the CMS messageDigest.
asn1crypto==1.5.1
# Pulled in by pyhanko. Used directly only in tests, to generate a throwaway
# self-signed certificate in memory.
cryptography==50.0.2

# Perceptual hashing for duplicate detection, and for the photo detector later.
# Brings scipy and PyWavelets (phash needs a DCT, whash a wavelet transform).
imagehash==4.3.2

# Step 8: the reviewer API. FastAPI needs this to parse multipart uploads.
# Resolved on Python 3.12 / macOS here.
python-multipart==0.0.32
